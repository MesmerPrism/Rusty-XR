Public Core

Reusable XR data contracts before framework adapters.

Rusty XR keeps shared Rust/XR concepts small, typed, testable, and independent of any one application shell. App repositories keep package identity, native platform integration, rendering policy, assets, releases, and target-device validation.

  • Plain Rust contracts
  • Quest and Android diagnostics
  • Camera, depth, SDF, particles
  • BLE, LSL, Polar H10 models
  • Optional adapters later

Utility Foundation

The first examples include synthetic contracts-only layout and composite feedback session demos plus a minimal Rust-native Android APK smoke test. Hardware/OpenXR/native-adapter examples remain deferred until the public utility surface is stable. The repo now tracks opt-in serialization, schema export, adapter policy, provenance, and boundary scanning as first-class checks.
