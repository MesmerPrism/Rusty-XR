## Matrix Rules

- Prefer new small examples when a reusable module combination has no public
  proof.
- Do not add examples that require private package names, private assets,
  generated captures, or downstream-only launch identities.
- Keep hardware-dependent examples explicit about what can be built without a
  headset and what requires device validation.
- When a source example proves a reusable contract, move the contract into the
  owning crate before adding more app behavior.
