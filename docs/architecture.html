Architecture

Shells own platforms. Rusty XR owns contracts.

The public workspace is useful when application shells can depend on shared models without inheriting a product's renderer, permissions, assets, or release pipeline.

Stable Center

        
rusty-xr-contracts is the shared center for plain data: math, poses, frame timing, eye views, camera/depth metadata, hand snapshots, media layers, interaction rays, room mesh state, capture lifecycle metadata, depth query summaries, render payloads, and counters.

      

      

        
Outer Utility Crates

        
Utility crates build on contracts without pulling in native platform dependencies. This keeps tests fast and lets downstream shells choose their own Android, OpenXR, Vulkan, Makepad, Unity, or LSL integration strategy.
